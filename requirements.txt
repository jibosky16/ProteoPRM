# OPTIONAL: GPU ACCELERATION (NVIDIA CUDA via PyTorch — not required)
# ============================================================================
# GPU acceleration in ProteoPRM = AlphaPeptDeep spectrum/RT prediction and
# model calibration running on PyTorch CUDA. Fragment matching, EIC
# extraction, and scoring intentionally run on CPU (faster for PRM spectra).
#
# EASIEST PATH (recommended): run  `python setup_venv.py`  — it detects an
# NVIDIA GPU automatically (nvidia-smi) and installs the matching CUDA
# PyTorch build. No manual steps, and CPU-only machines are unaffected.
#
# MANUAL PATH: the plain `torch==2.10.0` pin above installs whatever wheel
# PyPI serves (usually CPU-only on Windows). To switch to CUDA explicitly:
#   CUDA 12 drivers: pip install torch==2.10.0 --force-reinstall --index-url https://download.pytorch.org/whl/cu124
#   CUDA 11 drivers: pip install torch==2.10.0 --force-reinstall --index-url https://download.pytorch.org/whl/cu118
#   CPU-only Torch:  pip install torch==2.10.0 --force-reinstall --index-url https://download.pytorch.org/whl/cpu
# Check your driver's CUDA level with: nvidia-smi
#
# The CUDA wheels bundle the CUDA runtime and kernels for every supported
# NVIDIA architecture (plus PTX forward-compatibility for newer cards), so
# one wheel covers GTX 900-series through the latest RTX generation — only
# a reasonably recent NVIDIA driver is required. No CUDA Toolkit needed.
#
# CuPy / cuML are NOT used by ProteoPRM anymore and need not be installed.
# Intel/AMD/Apple GPUs are not CUDA-capable; the app uses CPU automatically.
# ============================================================================
